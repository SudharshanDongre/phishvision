# PhishVision - Comprehensive Project Documentation

## PROJECT OVERVIEW
================================================================================
PhishVision is an advanced Machine Learning-powered phishing detection system 
that combines a robust backend, interactive web interface, and real-time 
browser extension to protect users from malicious websites. The system uses 
multiple ML models to analyze URL features and classify websites as either 
phishing or legitimate with confidence scores.

**Primary Technology Stack:**
- Backend: Python, FastAPI, scikit-learn, XGBoost
- Frontend: Streamlit (Web App)
- Browser Extension: JavaScript (Chrome Extension Manifest V3)
- ML Models: Gradient Boosting, XGBoost, Random Forest, Stacking Ensemble


## PROJECT STRUCTURE
================================================================================

### Core Python Files
----------------------
1. **train.py** - Model Training Pipeline
   - Loads training data from Phishing.csv
   - Trains 4 different ML models:
     * Gradient Boosting Classifier (model_gb.pkl)
     * XGBoost Classifier (model_xgb.pkl)
     * Random Forest Classifier (model_rf.pkl)
     * Stacking Classifier - ensemble of GB+RF (model_stack.pkl)
   - Handles label mapping: -1 = Phishing, 1 = Safe
   - XGBoost uses different encoding: 0 = Phishing, 1 = Safe
   - Test/train split: 80/20 with random_state=42
   - Saves all trained models as pickle files

2. **api.py** - FastAPI REST API Server
   - Loads all 4 trained models on startup
   - Exposes POST endpoint: /predict
   - Request format: {"url": string, "model": string (default: "stack")}
   - Response format: {
       "url": string,
       "verdict": "Phishing" or "Safe",
       "is_phishing": boolean,
       "confidence": float (0-100)
     }
   - Handles model-specific prediction mappings:
     * XGB: 0 = Phishing, 1 = Safe
     * Others: -1 = Phishing, 1 = Safe
   - Calculates confidence from predict_proba()
   - Runs on port 8000 by default

3. **extractor.py** - Feature Engineering Module
   - extract_features(url) -> list of 30 features
   - Implemented features (F1-F8):
     * F1: IP Address in URL detection (regex pattern)
     * F2: URL Length classification (short/medium/long)
     * F3: URL Shortening service detection (bit.ly, goo.gl, etc.)
     * F4: @ Symbol presence
     * F5: Double slash redirection
     * F6: Dash (-) in domain name
     * F7: Number of subdomains
     * F8: SSL/HTTPS check
   - F9-F30: Placeholder features (set to 0)
   - Includes dns_resolves() helper function (unused)
   - Auto-prepends https:// if protocol missing
   - Returns feature vector as list

4. **app.py** - Streamlit Web Application (48.2 KB)
   - Full cyber dark theme with custom CSS
   - Fonts: Share Tech Mono, Orbitron, Rajdhani
   - Color scheme: #050a0f (background), #00ff88 (primary), #00c8ff (accent)
   - Custom components:
     * cyber_header() - Animated header with neural theme
     * threat_card() - Metric display cards
     * result_banner() - Phishing/Safe verdict display
     * section_title() - Section headers
     * load_selected_model() - Model loader function
   - Features:
     * Single URL scanning
     * Batch URL scanning from file upload
     * Model selection (GB, XGB, RF, Stack)
     * Real-time confidence visualization
     * Plotly-based charts and animations
     * Hover effects and transitions
   - Page config: Wide layout, sidebar expanded

5. **t.py** - (Empty file - possibly test file)

### Feature Extraction Details
-------------------------------
The system extracts 30 features from each URL:

**Implemented (8 features):**
1. IP Address presence: -1 if IP found, 1 otherwise
2. URL length: 1 (<54), 0 (54-75), -1 (>75)
3. Shortening service: -1 if detected, 1 otherwise
4. @ symbol: -1 if present, 1 otherwise
5. Double slash: -1 if found after position 7, 1 otherwise
6. Dash in domain: -1 if present, 1 otherwise
7. Subdomain count: 1 (≤1), 0 (2), -1 (≥3)
8. SSL state: 1 (https), -1 (http)

**Placeholder (22 features):** Set to 0 (F9-F30)
- Could include: WHOIS data, DNS records, page content analysis, 
  domain age, page rank, external links, etc.


## MODEL SPECIFICATIONS
================================================================================

### Model Performance Characteristics
--------------------------------------
1. **Gradient Boosting (GB)**
   - Best for: Balanced accuracy
   - Estimators: 100
   - Label encoding: -1/1

2. **XGBoost (XGB)**
   - Best for: Speed and efficiency
   - Special encoding: 0 (phishing) / 1 (safe)
   - Default parameters

3. **Random Forest (RF)**
   - Best for: Robustness
   - Estimators: 100
   - Label encoding: -1/1

4. **Stacking Ensemble (STACK)** ⭐ RECOMMENDED
   - Base models: GB + RF
   - Meta-learner: Logistic Regression
   - Best overall performance
   - Default choice in extension


### Prediction Logic (Critical)
--------------------------------
⚠️ IMPORTANT: Different models use different encodings!

**api.py prediction mapping:**
```python
if model_key == "xgb":
    is_phishing = (int(prediction) == 0)  # XGB: 0=Phishing
else:
    is_phishing = (int(prediction) == -1)  # Others: -1=Phishing
```

**Confidence calculation:**
- Uses predict_proba()[0] for all models
- prob[0] = phishing probability
- prob[1] = safe probability
- Confidence = selected class probability × 100

## TROUBLESHOOTING
================================================================================

### Common Issues
-----------------
1. **Extension shows "API Connection Error"**
   - Solution: Start FastAPI server (uvicorn api:app)
   - Verify: http://localhost:8000/docs should load

2. **Models not found error**
   - Solution: Run `python train.py` first
   - Verify: 4 .pkl files exist in project root

3. **Import errors**
   - Solution: Install requirements: `pip install -r requirements.txt`
   - Activate virtual environment if using one

4. **Extension doesn't load**
   - Verify manifest.json is valid
   - Check Chrome Extensions page for errors
   - Reload extension after code changes

5. **Streamlit theme not applied**
   - Clear browser cache
   - Restart Streamlit server
   - Check CSS injection in app.py
